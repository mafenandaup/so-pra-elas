# Só pra Elas

O Só pra Elas é uma Autoescola Fictícia pensada por mulheres, para mulheres. Reforça a inclusão do público feminino no meio automobilístico e oferece diversos serviços como Aquisição da primeira CNH, Cursos de reciclagem e Aulas de reforço.

Sendo assim, um CFC pluralizado e completamente pensado para aumentar a independência das mulheres no volante.

Esse projeto foi feito primordialmente como meio de revisão e aprendizagem de TypeScript, Estilização e Layout WEB, Boas práticas de código e organização de pastas.

Possui uma interface intuitiva e responsiva, e utiliza ícones para a associação visual de funções.


## Pré-requisitos

- **Node.js** (versão 16 ou superior)
- **npm** (gerenciador de pacotes do Node.js)
- **Git** (para clonar o repositório)
- **Vite** (ferramenta de build para o frontend)

## Dependências

- **Framer Motion (Biblioteca de animações flúidas)**
- **FontAwesome (Biblioteca para ícones customizáveis)**

## Contribuições 

Este projeto aceita contribuições diversas, como pull requests, conserto de bugs e feature requests. Caso deseja contribuir, é recomendável que leia as instruções de instalação abaixo:

### Instalação

Siga os passos abaixo para instalar e configurar o projeto:

 1. Clone o repositório
```bash
git clone https://github.com/mafenandaup/so-pra-elas.git
cd so-pra-elas
```

 2. Instale as dependências no front-end:
```bash
cd spe-client
npm install
```

3. Inicialize o front-end  (certifique-se de estar na spe-client)

```bash
npm run dev
```
